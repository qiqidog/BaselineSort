# BaselineSort（基线排序）
BaselineSort（也叫线段排序）是一种基于线段高度与基线累加思想的稳定排序算法，属于选择排序的变体。

## 核心思想
把每一个数字想象成一根竖直线段的高度：
1. 设置全局基线变量 `baseSum`，初始值为0。
2. 在所有还未移除的活跃线段中，找到最小高度。
3. 将基线加上这个最小高度，向上抬升。
4. 所有活跃线段，全部减去这个最小高度。
5. 如果某条线段高度变为0，它原始的值就等于当前基线。把基线存入排序结果，并标记这条线段已移除。
6. 重复循环，直到所有线段都被取出。

## 算法特性
- 时间复杂度：$O(n^2)$
- 空间复杂度：$O(n)$
- 稳定性：✅ 稳定排序（相等元素的相对顺序保持不变）
- 非原地排序
- 分类：选择排序变体，教学演示型算法

> 该算法仅用于学习和演示，不适合大数据场景使用。

## 示例
输入数组：`[3, 2, 1, 4]`
升序输出：`[1, 2, 3, 4]`
降序输出：`[4, 3, 2, 1]`

支持重复数字：
输入：`[4, 2, 2, 5]`
升序输出：`[2, 2, 4, 5]`
