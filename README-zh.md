# BaselineSort（基线排序）
BaselineSort（也叫线段排序）是一种基于线段高度与基线累加思想的排序算法，属于选择排序的变体。

## 核心思想
把每一个数字想象成一根竖直线段的高度：
1. 设置全局基线变量 `baseSum`，初始值为0。
2. 在所有非0活跃线段中，找到当前最小高度。
3. 将基线加上这个最小高度，向上抬升整体基线。
4. 所有活跃线段，全部减去本轮最小高度。
5. 调用 moveLeft 函数，将所有非0线段左移、产生的0空位统一右移。
6. 线段归零后，当前基线值即为该元素原始数值，将其存入排序结果。
7. 重复循环，直到所有线段全部排序完成。

## 算法特性
- 时间复杂度：$O(n^2)$
- 空间复杂度：$O(n)$
- 稳定性：❌ 不稳定排序（当前实现会打乱相等元素相对顺序）
- 非原地排序
- 分类：选择排序变体，教学演示型算法

> 该算法仅用于学习和演示，不适合大数据场景使用。

## 示例
输入数组：`[3, 2, 1, 4]`
升序输出：`[1, 2, 3, 4]`
降序输出：`[4, 3, 2, 1]`

支持重复数字：
输入：`[4, 2, 2, 5]`
升序输出：`[2, 2, 4, 5]`
